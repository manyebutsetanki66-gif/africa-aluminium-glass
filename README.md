# Africa Aluminium & Glass — Website Redesign Concept

An independent responsive React + Vite website redesign concept for Africa Aluminium & Glass Industries in Maseru, Lesotho. Created as a Bytecraft portfolio demonstration.

## Features
- Responsive desktop/mobile navigation
- Company introduction and product catalogue
- Direct product enquiry links that preselect the chosen product
- Expandable service information
- Filterable residential/commercial concept gallery
- Quote form that prepares a WhatsApp message for the visitor to review and send
- Phone, WhatsApp and Google Maps links

## Run locally
Requirements: Node.js 20+ and npm.

```bash
npm install
npm run dev
```

Open the local address printed by Vite (usually http://localhost:5173).

To create a production build:
```bash
npm run build
npm run preview
```
